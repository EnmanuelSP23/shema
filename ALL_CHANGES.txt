[5] FIX IMAGE UPLOADS (9051eac, 420f13b)
Fixed two issues preventing uploaded product images from displaying:

ISSUE 1 — Storage RLS Policy Error:
  Symptom: "Failed to upload image" + "new row violates row-level security policy"
  Fix: Added Supabase Storage policies for the `product-images` bucket:
    - INSERT policy: allows public uploads (bucket_id = 'product-images')
    - SELECT policy: allows public reads (bucket_id = 'product-images')
  Note: Bucket must also be set to Public in Supabase Dashboard → Storage

ISSUE 2 — Next.js Image Component Blocking External Images:
  Symptom: Image upload succeeds but image doesn't render on the page
  Fix: Added `images.remotePatterns` to next.config.ts to whitelist *.supabase.co
  This is required because Next.js blocks external image domains by default.

FILES MODIFIED:
- next.config.ts — Added images.remotePatterns for *.supabase.co

SUPABASE STORAGE SETUP REQUIRED (for new projects):
1. Create a Storage bucket named "product-images" (set to Public)
2. Add these SQL policies via Supabase SQL Editor:
   CREATE POLICY "Allow public uploads" ON storage.objects
     FOR INSERT WITH CHECK (bucket_id = 'product-images');
   CREATE POLICY "Allow public reads" ON storage.objects
     FOR SELECT USING (bucket_id = 'product-images');

[8] HOMEPAGE IMAGE FIX + PRODUCTS PAGE BUG FIX (2026-09-20)

ISSUE 1 — Hero image on homepage looked bad:
  Symptom: The SHEMA logo image on the right side of the hero section
  had object-contain with no styling, appearing as a flat rectangle.
  Fix: Changed to object-cover with rounded-3xl, shadow-2xl, and adjusted
  height (h-48 on mobile, md:h-[420px] on desktop).

ISSUE 2 — Products page showed "No products found" despite having products:
  Symptom: /products page displayed "Showing 0 of 11 products" and
  "No products found matching your criteria" even with no filters applied.
  Root cause: useMemo dependency array was missing `products`. When the
  page loaded, products was [], filteredProducts was calculated as [].
  When Supabase responded and updated state, useMemo didn't recalculate
  because `products` wasn't in the dependency array.
  Fix: Added `products` to useMemo dependencies.

FILES MODIFIED:

  rounded-3xl, shadow-2xl, adjusted height for mobile/desktop
- src/app/products/page.tsx — Added `products` to useMemo dependency array
