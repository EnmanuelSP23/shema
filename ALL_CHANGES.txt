ENVIRONMENT VARIABLES REQUIRED (set in Netlify dashboard):
- NEXT_PUBLIC_SUPABASE_URL — Your Supabase project URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY — Your Supabase anonymous key
- NEXT_PUBLIC_ADMIN_PASSWORD — Password for /admin access

NETLIFY DEPLOYMENT STEPS:
1. Go to Netlify Dashboard → your site → Site settings → Environment variables
2. Add all three env vars listed above
3. Push to git (git push) — Netlify auto-deploys
4. After deploy, visit https://your-site.netlify.app/admin
5. Enter the password you set in NEXT_PUBLIC_ADMIN_PASSWORD

ADMIN PAGE FEATURES:
- Password-protected access (stored in sessionStorage)
- Product list table with image thumbnails
- Add new product
- Edit existing product (pre-filled form)
- Delete product with confirmation
- Image upload to Supabase Storage
- Fields: brand, name, size, color, price, category, description
